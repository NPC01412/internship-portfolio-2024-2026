# 企業網路拓樸上機考

這是 1141「資訊網路」的 Packet Tracer 上機考作品。請用 Cisco Packet Tracer 8.2.2 或相容版本開啟 [network-topology.pkt](network-topology.pkt)。

拓樸以多個 VLAN 分隔不同部門的電腦，並使用交換器、多層交換器與路由器串接。檔案也放入伺服器、印表機與 IP 電話，練習主機位址、閘道及跨網段連線的規劃。原作業使用 VLAN 10、20、25、30、40、50、60、70；各網段多以 `192.168.x.0/24` 規劃。

這份 `.pkt` 保留課堂模擬設備的設定及測試用交換器密碼。它不是實際環境的網路設定，也不應直接套用到真實設備。整理作品集時，我在 Packet Tracer 開啟檔案並核對拓樸畫面；沒有重建或改寫拓樸。原始說明文件含學號及考試文字，未一併上傳。
