# 寶可夢系列介紹網站

這是 1131「基礎程式設計（一）」的個人網頁作業。網站有八個頁面，練習導覽列、圖片輪播、內容排版、表格、外部連結和嵌入影片。從 [首頁](index.html) 開始瀏覽；直接開啟 HTML 檔即可，不需要後端服務。

這裡保留 2024 年 12 月版本的 HTML 與 CSS，沒有改成其他主題。整理檔案時發現原資料夾少了九個網頁引用的圖片，因此從同一作業的較早備份補齊。頁面設計與文字未改寫。

## 圖文來源與使用範圍

網站使用寶可夢系列的角色、商品、地圖、影片及介紹文字，也參考了官方網站、百科與其他網站。[架構分析頁](information.html)列有當年記錄的部分參考連結。這些第三方圖文及商標的權利仍屬原權利人；本站是非商業的課程作業與作品集展示，並非官方網站，也沒有取得全面轉載授權。課堂教育用途的說明不等於公開散布的授權保證。如需再使用相關素材，請向權利人確認。

網站所嵌入的 YouTube 影片、Google 地圖及外部網站，由各平台提供，能否顯示取決於當時的連線與對方網站設定。
