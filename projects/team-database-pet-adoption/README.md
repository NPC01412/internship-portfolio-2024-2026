# 寵物領養與追蹤管理系統｜資料庫管理團隊專題

這是 1142「資料庫管理」團隊專題，延伸前一學期的寵物領養題目。團隊設計使用者、寵物、收容所與領養申請之間的關聯，實作會員與管理員的不同操作流程。我與組員輪流撰寫資料庫及系統功能，也參與成果整理；無法將整套系統的程式碼歸為個人完成。

[原始期末報告](original-report.pdf)收錄資料需求、表格關聯、操作畫面與問題檢討。報告第 21 至 23 頁的排序、刪除防呆及申請流程改善屬於後續方案，不能當成已完成的功能。第 24 頁另記錄團隊使用 AI 協助程式、文件與架構整理。

本資料夾公開的是團隊報告；未附團隊原始碼與資料庫。報告中的使用者資料與系統畫面是當時課程展示內容。
