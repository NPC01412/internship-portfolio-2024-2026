# 實習作品集

這裡整理了我從 2024 年 9 月到 2026 年 10 月的課程作品與專案經驗。目前已完成拼圖遊戲和訂單管理網頁的公開展示版。其他作品列在下方。確認原始碼、素材及團隊的公開範圍後，我會再逐一加入。

## 已整理的個人作品

### 拼圖遊戲｜1132 基礎程式設計（二）期末專案

我用 C# Windows Forms 製作拼圖遊戲。玩家可選擇 3×3、5×5 或 10×10 格，再拖曳圖片交換位置。整理展示版時，我修正了圖片讀取路徑與完成判定，並測試五張圖片在三種格數下的載入和切割。開發過程有使用 AI 協助，程式整合與修改由我完成。

[查看拼圖專案與執行說明](projects/puzzle-game/README.md)

### 訂單管理網頁｜1142 網際網路程式設計期末作業

這是使用 ASP.NET Core 8 MVC 和 Razor 製作的訂單管理網頁。使用者可以依地區或關鍵字查詢訂單，也能分頁瀏覽、新增、修改和刪除資料。課堂原版連接 SQL Server。展示版改用本機 JSON 和虛構訂單，不需要學校的資料庫，也不含原本的連線帳密。

[查看訂單管理專案與執行說明](projects/order-manager/README.md)
